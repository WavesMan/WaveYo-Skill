# WaveYo Skill v1.3.0 — 版本快照

> 归档时间：2026-06-25
> 归档原因：升级到 v2.0.0（大版本，含专题集重组）— 新增前端 UI/UX 与上游错误处理两个专题，入口与专题通用化，合并策略统一为保留提交的 Merge PR
> 全文快照：[`../archive/v1.3.0/`](../archive/v1.3.0/)

## v1.3.0 摘要

- **蒸馏范围**：公开仓库 + 画像分析文件；代码证据驱动
- **Skill 结构**：`SKILL.md`（入口）+ `persona.md`（5 层工程人格）+ `work.md`（技术工作技能）+
  `collaboration.md`（人机协作规范）+ 7 个领域专题
- **7 个领域专题**（归档版）：go-service-scaffold、multi-level-cache、object-storage-integration、
  gateway-bff-pattern、python-ssh-audit、project-delivery、git-collaboration
- **当时的合并策略**：squash merge（**v2.0.0 已改为保留原始提交与合并节点的 Merge PR**）
- **不包含**：前端 UI/UX 专题、上游错误处理专题、界面动态验收要求、错误链保留规则

## 与 v2.0.0 的差异要点

| 项 | v1.3.0 | v2.0.0 |
|---|---|---|
| 前端界面规范 | 仅有组件拆分与工程约束 | 新增 `skills/frontend-ui-ux.md`（结构/控件/浮层/状态/视觉/可访问性/动态验收） |
| 上游依赖错误 | 分散在各子专题 | 新增 `skills/upstream-error-handling.md`（错误链/分类/诊断/映射/重试/验证） |
| 专题集 | 7 个领域实现类专题 | 重组为工程规范类专题（命名/注释/日志/最小闭环/协作/Git/CI） |
| 合并策略 | squash merge | 保留原始提交与合并节点的 Merge PR（squash 需明确要求） |
| 入口定位 | 偏单项目适配 | 跨项目通用，具体项目约定优先 |
| 专题链接 | 部分入口指向 `references/` | 统一指向实际存在的 `skills/` |
| 元数据 | 依赖 `meta.json` | 移除该文件，版本号置于 `SKILL.md` frontmatter |
